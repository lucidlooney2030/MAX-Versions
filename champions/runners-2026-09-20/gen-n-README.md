# Gen-N — Wound-aware Halbach barrel / 12-coil 3φ (runner-up)

Wound-compliant evolution of withdrawn Gen-G. Radial bobbins + dual cylindrical gaps with explicit copper budget.

## Wound envelope

| Param | Value |
|-------|-------|
| Wire | **26 AWG** OD **0.45 mm** |
| Turns | **100** / bobbin |
| fill | **0.70** |
| `wind_build_radial` (tip) | **0.945 mm** (`3×0.45×0.7`) |
| `wind_build_circ` (side) | **0.63 mm** |
| `wound_w` / `wound_d` | **12.26 / 16.95 mm** |
| Slot W×D | **~13.8 × 19.0 mm** (clears wound) |
| `run_clear` magnet→**wound** tip | **≥ 0.85 mm** (geometric bare gap ≥ ~2.0 mm) |

Stator ID/OD opened vs Gen-G (34 / 94) and slots widened for wound pack.

## Magnets

12× Ø20 outer inward @ R=52 + 4× Ø20 inner outward @ R=22 + 48× Ø5 Halbach assists. Pockets Ø20.3×5.2 / Ø5.3×5.2.

## Modular

Shaft Ø8 / 608ZZ Ø21.85; endbell **6× M3 @ R≈54** (barrel family).

## Parts

`rotor_outer_drum` ×1, `rotor_inner_hub` ×1, `stator_annulus` ×1, `coil_former` ×12, endbells, collars.

**Wind before assembly.** Runner-up — champion is Gen-M.
